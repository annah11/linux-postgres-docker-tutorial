# Tutorial: Linux, PostgreSQL and Docker

Hands-on work from my study plan (Minab I.T Solutions internship).

| Folder | What it contains |
|---|---|
| `linuxTut/` | FND-01: a bash script that loads env variables and checks ports |
| `postgresql/` | Postgres 16 + pgAdmin in Docker Compose |
| `dockertut/` | FND-02: Postgres 16 + Hasura + pgAdmin with named volumes and healthchecks (see its README) |

Secrets live in `.env` files, which are git-ignored. Each project ships a `.env.example` with placeholders.
